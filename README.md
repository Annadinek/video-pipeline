# video-pipeline

Автоматический конвейер обработки и публикации видео.

| Папка | За что отвечает | Что кладу я (Анна) | Что делаешь ты (Клод) |
|---|---|---|---|
| `1-Исходники-видео` | Снятое сырое видео | Кладу сюда отснятый ролик | Беру отсюда файл в обработку |
| `2-Готовые-ролики` | Обработанные ролики и нарезка | Ничего | Кладу сюда готовое видео и Shorts/Reels |
| `3-Тексты-и-сценарии` | Сценарии, заголовки, описания, посты | Ничего | Пишу тексты и складываю сюда |
| `4-Аналитика` | Отчёты, что сработало | Говорю цифры просмотров | Веду отчёты и заметки |
| `music` | Фоновая музыка для роликов | Выбираю музыку один раз на настройке | Скачиваю выбранное и подмешиваю под голос |
| `voice` | Образец твоего голоса | Кладу 1–2 минуты чистой речи | Использую для озвучки/проверки голоса |
