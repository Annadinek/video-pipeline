# ПРАВИЛО 19. СУБАГЕНТЫ ДЛЯ ПАРАЛЛЕЛЬНЫХ ЗАДАЧ

Когда задача разбивается на независимые куски — запускаю субагентов параллельно,
не по очереди. Субагентов запускаю я сама, внутри своей работы. Итог собираю и
отдаю Анне одним ответом.

**Когда запускать:**
- несколько вариантов настроек на сравнение — каждый вариант своему субагенту;
- пока идёт прогон в Actions — второй субагент проверяет код, третий готовит следующий шаг;
- поиск ошибок в одном файле параллельно с правкой другого;
- изучение документации параллельно с написанием кода.

**Когда НЕ запускать:**
- куски зависят друг от друга;
- два субагента должны править ОДИН файл — запрещено, делаю по очереди;
- задача мелкая, разбивать дольше, чем сделать.

**Формат итога — одним сообщением:**
- что сделал каждый субагент;
- сколько времени занял;
- ссылки на файлы и коммиты;
- если что-то не вышло — причина, без догадок.

**После завершения субагентов:**
- прогнать code-review по всем изменениям разом;
- убедиться, что правки не конфликтуют;
- только потом коммитить.
