# 2. РЕШЕНИЯ И ПОЧЕМУ

**Одиннадцать ролей, не семнадцать.** Больше — распыление. Меньше — дыры в продажах и качестве.

**Три роли на Диске, восемь на GitHub.** Наставник, Методолог, Хранитель отдельно от машины.

**Структура по этапам, не по ролям.** У этапа есть состояние: не начат, в работе, закрыт. У должности состояния нет, циклу нечем управлять.

**Скиллы плоско в .claude/skills.** Один скилл нужен двум ролям. Разложить по ролям — начнётся копирование и расхождение версий.

**Мозг на Диске, копия на GitHub.** Я пишу память сама. Ночью синхронизация тянет в репозиторий.

**Нет папки archive и еженедельных копий.** Git хранит каждое сохранение навсегда. Вместо копий — защита синхронизации: не удаляем, при усыхании файла вдвое останавливаемся и шлём сигнал.

**Нет отдельного queue.json.** Очередь внутри pipeline.json.

**10-measure не убираем.** В stages записано что делать, в workflows — когда. Это не дубль.

**Vizard остаётся.** См. пункт 2 ключевых выводов. AI-Youtube-Shorts-Generator записан в резерв на март 2027.

**Правило дублей:** не больше одного текстового ролика на два с лицом.

**Instagram через Meta API бесплатен.** Нужны бизнес-аккаунт, привязка к Facebook, проверка приложения. Идёт неделями. Пока идёт — SMMplanner.

**TikTok на полный автомат не встанет.** Без аудита ролик уходит в черновики.

**Два бота, не один.** Продажи и техника в одну ленту не сваливаются.
