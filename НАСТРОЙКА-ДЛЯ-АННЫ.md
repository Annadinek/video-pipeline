# Настройка один раз руками — пошагово

Это делается ОДИН раз. Дальше конвейер работает сам. Нигде не пиши слово «скопируй»
без места — я везде указываю, куда именно вставлять. Если что-то не совпало с тем, что
видишь на экране — не угадывай, напиши мне, и я подскажу.

Тебе нужно получить 4 «ключа» и вставить их в одно место (GitHub Secrets):
`YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`, `TELEGRAM_BOT_TOKEN`.

---

## ЧАСТЬ 1. Токен Telegram-бота (5 минут)

1. Открой Telegram, в поиске сверху набери **@BotFather**, открой чат с ним (у него синяя галочка).
2. Внизу нажми **Start** (или напиши `/start`).
3. Напиши команду `/token`, он предложит выбрать бота — выбери **@dinekanna_bot**.
   (Если бота ещё нет — напиши `/newbot` и следуй подсказкам, имя можно `dinekanna_bot`.)
4. BotFather пришлёт строку вида `123456789:AAE...очень_длинная`. Это и есть токен.
5. Держи это сообщение открытым — строку вставим в Шаге «GitHub Secrets» ниже как
   **TELEGRAM_BOT_TOKEN**.

Важно один раз: открой чат со своим ботом @dinekanna_bot и нажми в нём **Start**,
иначе бот не сможет тебе писать.

## ЧАСТЬ 2. Доступ к YouTube (15–20 минут, всё в браузере)

### Шаг 2.1. Создать проект
1. Зайди на **https://console.cloud.google.com/** под тем аккаунтом Google, к которому
   привязан канал «Анна Динэк».
2. Вверху слева нажми на выпадающий список проектов → **New Project** (Новый проект) →
   имя `video-pipeline` → **Create**.

### Шаг 2.2. Включить YouTube API
1. В строке поиска вверху набери **YouTube Data API v3**, открой её.
2. Нажми синюю кнопку **Enable** (Включить).

### Шаг 2.3. Экран согласия — ОБЯЗАТЕЛЬНО «Production»
1. Слева меню → **APIs & Services** → **OAuth consent screen**.
2. Выбери **External** → **Create**.
3. Заполни только обязательное: App name `video-pipeline`, свой email в двух полях. **Save and continue**
   до конца, ничего больше не добавляй, в конце **Back to dashboard**.
4. На странице OAuth consent screen найди кнопку **PUBLISH APP** (Опубликовать приложение) →
   подтверди **Confirm**. Статус должен стать **In production**.
   ❗Это самый важный пункт: если оставить «Testing», доступ сам сломается через 7 дней.

### Шаг 2.4. Создать OAuth-клиент
1. Слева → **APIs & Services** → **Credentials**.
2. **+ Create Credentials** → **OAuth client ID**.
3. Application type: **Web application**.
4. В разделе **Authorized redirect URIs** нажми **+ Add URI** и вставь ровно это:
   `https://developers.google.com/oauthplayground`
5. **Create**. Появится окно с двумя строками:
   - **Client ID** → это будет **YT_CLIENT_ID**
   - **Client secret** → это будет **YT_CLIENT_SECRET**
   Оставь окно открытым, значения понадобятся в следующем шаге и в GitHub Secrets.

### Шаг 2.5. Получить refresh-токен через OAuth Playground
1. Открой **https://developers.google.com/oauthplayground/**
2. Справа вверху нажми на **шестерёнку** (⚙). Поставь галочку **Use your own OAuth credentials**.
3. В появившиеся поля вставь **Client ID** и **Client secret** из Шага 2.4. Закрой шестерёнку.
4. Слева в поле **Input your own scopes** вставь ровно это (через пробел):
   `https://www.googleapis.com/auth/youtube.upload https://www.googleapis.com/auth/youtube.force-ssl`
5. Нажми синюю **Authorize APIs**.
6. Откроется вход Google — войди аккаунтом канала. ❗Если появится выбор аккаунтов и среди них
   есть отдельный «бренд-аккаунт» канала «Анна Динэк» — выбирай именно его, не личный.
7. Google скажет «приложение не проверено» → **Advanced** (Дополнительно) → **Go to video-pipeline (unsafe)** →
   **Continue/Allow**. Это нормально, приложение твоё.
8. Вернёшься в Playground. Нажми синюю **Exchange authorization code for tokens**.
9. В ответе справа найди строку **Refresh token** (начинается на `1//...`). Это **YT_REFRESH_TOKEN**.

### Шаг 2.6. Подтвердить канал по телефону
1. Открой **https://www.youtube.com/verify** под аккаунтом канала.
2. Подтверди номер телефона по SMS. Без этого YouTube не даёт ставить обложки.

## ЧАСТЬ 3. Вставить ключи в GitHub Secrets (5 минут)

1. Открой **https://github.com/Annadinek/video-pipeline**
2. Вкладка **Settings** (шестерёнка сверху репозитория) → слева внизу
   **Secrets and variables** → **Actions**.
3. Нажимай зелёную **New repository secret** и добавь по очереди 4 штуки
   (Name — строго как написано, Secret — вставь значение):

   | Name (имя) | Secret (что вставить) |
   |---|---|
   | `YT_CLIENT_ID` | Client ID из Шага 2.4 |
   | `YT_CLIENT_SECRET` | Client secret из Шага 2.4 |
   | `YT_REFRESH_TOKEN` | Refresh token из Шага 2.5 (строка на `1//...`) |
   | `TELEGRAM_BOT_TOKEN` | Токен бота из Части 1 |

   Каждый раз после вставки нажимай **Add secret**.

## Когда всё вставишь — напиши мне «ключи готовы»

Дальше я:
1. Проверю доступ (бот напишет тебе «Проверка связи ✅»).
2. Соберу плейлист музыки (спокойная + тёмная) и пришлю ссылку — выберешь.
3. Возьму самое старое видео из «Клауд сырое», обработаю и пришлю в Telegram на проверку.

Ничего из этого руками делать не нужно — только 4 ключа выше.
