# video-pipeline — конвейер обработки и публикации видео

## 1. Кто такая Анна и что за проект

Анна — эксперт-регрессолог. Работает одна, через браузер, не программист.
Цель — через видео-контент вырастить доход и аудиторию.
Этот репозиторий — автоматический конвейер: из одного длинного видео получаются
короткие вертикальные ролики, подписи и публикация.

Полное описание эксперта, голоса и аудитории — в **brain/FOUNDATION.md**.

## 2. Порядок чтения в начале сессии

**Для работы конвейера** читать строго по порядку:
1. brain/RULES.md
2. brain/FOUNDATION.md
3. brain/FORBIDDEN.md
4. brain/ROLES.md
5. state/pipeline.json
6. state/trigger.txt

**Для стратегического разговора** — плюс:
- brain/MEMORY.md
- brain/LIBRARY.md
- brain/PLAN.md

PLAN и LIBRARY конвейеру не нужны — на них контекст не тратить.

## 3. Схема цикла из семи этапов

Один ролик проходит семь этапов по очереди. Каждый этап описан в
`stages/NN-name/PROMPT.md`.

| Этап | Папка | Роль | Задача |
|---|---|---|---|
| 00 | stages/00-plan | Стратег | выбрать тему и угол |
| 01 | stages/01-script | Автор | сценарий под запись голосом |
| 02 | stages/02-cut | Режиссёр | нарезка через Vizard + вертикаль 9:16 |
| 03 | stages/03-color | Режиссёр | шум, чёткость, цвет, титры |
| 04 | stages/04-caption | Автор | три подписи: YouTube, Instagram, TikTok |
| 05 | stages/05-qa | Редактор | проверка (пропускать нельзя) |
| 06 | stages/06-publish | СММ | публикация на YouTube + уведомление Анне |

Двигает цикл `scripts/loop.py`. Этап **05-qa пропускать нельзя никогда**.
Если `qa.passed = false` — дальше не идём.

## 4. Правила

- Упрощать, не усложнять. Не добавлять сущностей сверх нужного.
- Только латиница в именах файлов и папок.
- Не угадывать пути — проверять реальную структуру перед записью.
- Две попытки. Не вышло дважды — в blocked, отчёт, идём дальше.
- Ключи и токены не выводить в чат и не писать в файлы. Только GitHub Secrets.
- Каждый шаг: сделал → проверил → доложил. Одной строкой.
- Все видимые Анне тексты — по-русски.
