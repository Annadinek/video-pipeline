# video-pipeline — конвейер обработки и публикации видео

Этот файл — **устройство проекта**: этапы, папки, что где лежит, порядок чтения
при старте. **Все правила поведения** (как работать, что не трогать, язык,
автопроверки, субагенты, память между сессиями) — в **brain/RULES.md**. Состояние
(что сделано, что не работает, следующий шаг) — в **HANDOVER.md**.

## ПРАВИЛО. ДВА КОНВЕЙЕРА, ОДИН РЕПОЗИТОРИЙ

Отменяет прежние договорённости про разделение. В одном репозитории живут ДВА
независимых производства. **Чужие файлы не трогать.**

**Этот чат — YouTube.** Вход: длинное видео с лицом. Обработка, нарезка, Shorts.

**Второй чат — Instagram и TikTok.** Вход: аудио Анны плюс папка картинок и
коротких видео с её телефона. Собирает ролик с нуля: приближение и отдаление
кадра, вставки, своя музыка, плотные субтитры. Лица в кадре может не быть. Это
ДРУГОЕ производство, а не настройки моего — не путать.

**Владеет ЭТОТ чат (YouTube):**
- `scripts/loop.py`, `audio_clean.py`, `stabilize.py`, `color.py`, `subtitles.py`,
  `fetch_youtube.py`, `vizard_cut_file.py`;
- `stages/00-plan … 06-publish`;
- `presets/audio.json`, `stab.json`, `color.json`, `subtitles.json`;
- `state/`, существующие `.github/workflows/`.

**Владеет ВТОРОЙ чат — всё с приставкой `reels_`:**
- `reels/`, `scripts/reels_*.py`, `stages/reels-*/`, `presets/reels_*.json`,
  `.github/workflows/reels-*.yml`.

**Общее, читают оба (в одиночку не переписывать):** `brain/`, `bank/`,
`CLAUDE.md`, `HANDOVER.md`.

**ВАЖНО про `scripts/loop.py`:** он ведёт ТОЛЬКО конвейер YouTube. Список `STAGES`
не подхватывает ничего из `reels/` и никакие этапы с приставкой `reels-` — в
loop.py стоит защита, которая отфильтровывает их из `STAGES`. У второго конвейера
свой запуск.

## 1. Кто такая Анна и что за проект

Анна — эксперт-регрессолог. Работает одна, через браузер, не программист.
Цель — через видео-контент вырастить доход и аудиторию.
Этот репозиторий — автоматический конвейер: из одного длинного видео получаются
короткие вертикальные ролики, подписи и публикация.

Полное описание эксперта, голоса и аудитории — в **brain/FOUNDATION.md**.

## 3. Схема цикла из одиннадцати этапов

Один ролик проходит одиннадцать этапов по очереди. Каждый этап описан в
`stages/NN-name/PROMPT.md`.

| Этап | Папка | Роль | Задача |
|---|---|---|---|
| 00 | stages/00-plan | Стратег | выбрать тему и угол |
| 01 | stages/01-script | Автор | сценарий под запись голосом |
| 02a | stages/02a-dupes | Режиссёр | пословная расшифровка (transcript.json), поиск дублей на горизонтали |
| 02b | stages/02b-audio | Режиссёр | звук: DeepFilterNet → подмес исходника → верх → громкость (`scripts/audio_clean.py`) |
| 02c | stages/02c-stab | Режиссёр | стабилизация картинки |
| 03 | stages/03-color | Режиссёр | цвет и сглаживание лица |
| 03a | stages/03a-cut | Режиссёр | нарезка вертикали 9:16 через Vizard (субтитры Vizard выключены) |
| 03b | stages/03b-subtitles | Режиссёр | свои субтитры с подсветкой на вертикальных кусках |
| 04 | stages/04-caption | Автор | три подписи: YouTube, Instagram, TikTok |
| 05 | stages/05-qa | Редактор | проверка (пропускать нельзя) |
| 06 | stages/06-publish | СММ | публикация на YouTube + уведомление Анне |

Обработка идёт на длинном горизонтальном видео (02a→02b→02c→03), затем Vizard
режет вертикаль (03a), и только после нарезки рисуются субтитры (03b) — иначе
Vizard обрежет бока и текст поедет.

Двигает цикл `scripts/loop.py`. **Источник истины по порядку и составу этапов —
список `STAGES` в `scripts/loop.py`**; при расхождении верить ему. Этап
**05-qa пропускать нельзя никогда**: если `qa.passed = false` — дальше не идём.

# КАК ВПИСЫВАТЬ ТЕКСТЫ В ФАЙЛ НОЛЬ (рабочий способ — делать так)

Мои Google-инструменты НЕ умеют писать в существующую таблицу на Диске (только читать/создавать новое). Поэтому в файл НОЛЬ вписываю так:
1. Анна присылает мне САМ файл .xlsx (загружает в чат).
2. Я открываю его локально (openpyxl), вписываю темы/тексты в нужную вкладку («Темы соцсети»), НЕ трогая остальные вкладки и её данные (добавляю аккуратным блоком).
3. Возвращаю готовый .xlsx через SendUserFile — Анна заливает его на Диск вместо старого.
Так каждую неделю: прислала файл → вернул с вписанными текстами.
