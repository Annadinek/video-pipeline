# ЭТАП 02a — ПОИСК ДУБЛЕЙ
Роль: Режиссёр (brain/ROLES.md)

Стоит ПЕРЕД звуком и цветом: дубли ищем до обработки, чтобы не красить и не
стабилизировать то, что потом вырежем. Порядок:
02-cut → **02a-dupes** → 02b-audio → 02c-stab → 03-color.

## ЧТО ЧИТАЮ
- outputs/ready/[id]/clip.mp4  (уже скачанный файл; этап сам ничего не качает)
- presets/dupes.json (настройки)

## ЧТО ДЕЛАЮ
Запускаю `scripts/find_dupes.py --input outputs/ready/[id]/clip.mp4`:
1. Распознаю речь через Whisper (faster-whisper) с метками времени.
2. Сохраняю расшифровку в ДВА файла — переиспользуем для субтитров,
   второй раз не распознаём:
   - outputs/ready/[id]/transcript.srt (с метками)
   - outputs/ready/[id]/transcript.txt (сплошным текстом)
3. Ищу дубли: фразу, сказанную дважды подряд слово в слово.
4. Если cut=on — РЕЖУ, но вырезанное НЕ выбрасываю (складываю в cut_out/).
   Если cut=off — только показываю список.

## КАК НАХОЖУ ДУБЛЬ (по словам, без процентов)
- Дубль — фраза, сказанная ДВАЖДЫ ПОДРЯД, слово в слово.
- Ищу повтор, который идёт подряд (между версиями 0 слов после чистки),
  совпадает слово в слово и длиной не меньше prefix_words слов.
- Приём так НЕ ловится: между повторами всегда стоит отличающееся слово
  («в каждом ВДОХЕ есть смысл, в каждом ВЗГЛЯДЕ есть смысл») — значит
  «подряд слово в слово» не выполняется.
- Меряю в СЛОВАХ, не в секундах (скорость речи гуляет) и не в символах
  (длинные слова врут). Проценты не использую — на коротких фразах обманывают.
- Сомневаюсь — не считаю дублем. Лучше пропустить, чем вырезать живое.
- Смотрю на слова подряд по всему ролику, поэтому повтор ловится одинаково
  и внутри куска, и на стыке двух соседних кусков.

## КАК РЕЖУ (cut=on)
- Режу только сам повтор: убираю ПЕРВУЮ версию (и паузу перед второй),
  оставляю вторую (обычно более полную).
- Режу по границам СЛОВ (word_timestamps Whisper), точно, не по опорным кадрам.
- Вырезанное НЕ выбрасываю: каждый кусок кладу отдельным файлом в
  outputs/ready/[id]/cut_out/ с именем по времени — можно послушать.
- Пишу ДВА видеофайла: обрезанный clip_nodupes.mp4 и ИСХОДНИК clip.mp4.
  Исходник не трогаю никогда.
- Режу только там, где повтор слово в слово и подряд. Сомневаюсь — не режу.
  Whisper распознаёт немного по-разному от запуска к запуску, поэтому
  вслепую не режем — вырезанное всегда можно проверить в cut_out/.

## НАСТРОЙКИ (presets/dupes.json)
- prefix_words 3 — минимум слов в повторе; фраза короче не считается
- cut — резать ("on") или только показывать ("off"); по умолчанию "on"
- fillers — слова-паразиты, которые чищу перед сравнением
  (ну, это, вот, как бы, значит)
- model / compute_type / language / vad_filter — параметры Whisper

Чистка перед сравнением: нижний регистр, ё→е, без пунктуации, без паразитов.
Лемматизации нет — намеренно (тяжело, не окупается).

## ЧТО ОТДАЮ
- outputs/ready/[id]/clip_nodupes.mp4 (обрезанный) + clip.mp4 (исходник, цел)
- outputs/ready/[id]/cut_out/*.mp4 (вырезанные куски по времени)
- outputs/ready/[id]/dupes.json (для машины): dupes, cut_seconds, cut_count,
  duration_before/after, cut_pieces
- outputs/ready/[id]/dupes_report.txt (для человека): что нашёл, сколько
  вырезано (секунды, куски, было→стало), какая фраза и куда сохранён кусок
- запись в state/pipeline.json (current.dupes)

## КОГДА СТОП
- нет ffmpeg/ffprobe или faster-whisper → blocked
- пустая расшифровка (речь не распознана) → blocked
- две неудачные попытки → blocked, отчёт, идти дальше
