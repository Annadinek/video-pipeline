## ЧТО ДЕЛАЮ (по порядку)
1. **Скачать** новый исходник из папки `reels_input` (Google-аккаунт dnkanna2005@gmail.com).
2. **Звук:** DeepFilterNet + подмес сухого сигнала `0.15` → `loudnorm` до −14 LUFS,
   true peak −1.0 dB. (Решение по звуку принято и проверено — другое не подбирать.)
3. **Вырезать паузы/запинки:** порог тишины −35 dB, мин. пауза 0.35 с, оставлять
   0.1 с с краёв склейки. Ориентир по темпу — образец: ~48 склеек за 60 с.
4. **Зум (zoompan):** на смысловых фразах приближение 1.00→1.12 за 2 с, на паузах
   отъезд обратно. Центр — по лицу (координаты из детекции). OpenCV только 4.x.
5. **Субтитры:** faster-whisper `large-v3`, ru, `word_timestamps=True`. Пословно,
   текущее слово подсвечено. Шрифт без засечек, белый, обводка 3 px, размер ≈1/18
   высоты, нижняя треть, отступ снизу 18%. **Проверка по `brain/FORBIDDEN.md`:**
   совпало — НЕ выпускать, написать в бот.
6. **Музыка:** только из Фонотеки YouTube Studio (чужое = страйки), −22 LUFS под голосом.
7. **Финал:** 1080×1920, 30 fps, H.264, 8 Мбит/с.
8. **Положить** готовый ролик в `reels_ready`.
9. **Удалить** исходник из `reels_input` — ТОЛЬКО после записи готового в `reels_ready`
   (место на диске Анны ограничено ~3.49 ГБ).
