## Что сделано по этапам

### 02a-dupes — поиск дублей / расшифровка (`scripts/find_dupes.py`, `presets/dupes.json`)
- Whisper (faster-whisper, medium, int8, ru, VAD) с пословными метками.
- Пишет расшифровку: `transcript.srt`, `transcript.txt`, `transcript.json`
  (пословно — переиспользуется субтитрами, второй раз не распознаём).
- Детектор дублей: фраза, сказанная дважды ПОДРЯД слово в слово, ≥ `prefix_words`
  слов; режет зону перезапусков целиком. Проверено на реальном ролике: ловит
  запинки, риторические приёмы (анафору) не трогает.
- **РЕЗКА ВЫКЛЮЧЕНА** (`cut: "off"`): длинные куски Анна вырезает вручную перед
  заливкой. Этап теперь только распознаёт и даёт `transcript.json`.

### 02b-audio — звук (`scripts/audio_clean.py`, `presets/audio.json`)
- Порядок фильтров (строгий): highpass=80 → afftdn(шумодав) → compand →
  alimiter(0.7) → loudnorm (2 прохода). Резка пауз — ПОСЛЕ (silencedetect).
- Принято на компьютере, НО потом Анна на телефоне услышала проблемы (см. «Что
  не работает»). Деэссер и вырез гула добавлены, но по умолчанию ВЫКЛЮЧЕНЫ.

### 02c-stab — стабилизация (`scripts/stabilize.py`, `presets/stab.json`)
- vidstab 2 прохода. Меряет тряску, пропускает если < `skip_below_px` (3.0).
- На реальном материале тряска ~0.2px → этап пропускается. Оставлен как страховка.

### 03-color — цвет и кожа (`scripts/color.py`, `presets/color.json`)
- Замер содержимого кадра через ffmpeg signalstats (не заголовок файла).
- Цвет: LUT `presets/cinema.cube` если есть, иначе авто-eq от замеров.
- Кожа: OpenCV, Haar-каскад находит лицо, сглаживание bilateralFilter ТОЛЬКО по
  коже (глаза/брови/волосы/фон не трогает), уровень medium. + лёгкий unsharp.
- **Принято** («картинка теплее, лицо в норме, кожа живая»).

### 03a-cut — нарезка вертикали (`stages/03a-cut/PROMPT.md`, скилл using-vizard-api)
- Vizard режет вертикаль 9:16 со слежением за лицом.
- **Субтитры Vizard ВЫКЛЮЧЕНЫ** (`subtitleSwitch: 0`) — свои рисуем в 03b.
- ⚠️ Ещё НЕ прогонялся сквозняком (см. «Что не работает»).

### 03b-subtitles — субтитры в кадре (`scripts/subtitles.py`, `presets/subtitles.json`)
- Вжигает субтитры (ASS/libass) в вертикальный кусок. По 3–5 слов на экран, по
  пословным меткам из `transcript.json`.
- Белый текст, чёрная обводка, внизу по центру, крупно.
- **Подсветка**: строка белая, звучащее сейчас слово — жёлтым, переезжает по
  словам (караоке). Жёлтое сохраняет чёрную обводку — читается на любом фоне.
- **Принято** («субтитры вижу, всё хорошо»).

## Принятые настройки и почему

| Где | Настройка | Значение | Почему |
|---|---|---|---|
| dupes.json | `cut` | **off** | Длинные куски Анна режет сама; авто-резка отключена по её решению |
| dupes.json | `prefix_words` | 3 | Ловит короткие повторы, приёмы не трогает (проверено на 13 местах) |
| audio.json | `target_lufs` / `true_peak_db` | -14 / -1 | Приняты по звуку |
| audio.json | `denoise_strength` | high | Принято (но см. звон ниже) |
| audio.json | `pauses` | on (-35дБ, 0.45с) | Режет паузы между словами |
| stab.json | `skip_below_px` | 3.0 | Тряски почти нет — не гоняем зря |
| color.json | насыщенность | потолок ×1.3 | Исходник тусклый; авто тянет, но не «кислотно» |
| color.json | кожа | OpenCV medium, только лицо | ffmpeg мылил весь кадр; нужно только кожу |
| subtitles.json | `font_size_pct` | 7.5 (от МЕНЬШЕЙ стороны) | На 9:16 это ширина → текст узкий, не 144px по высоте |
| subtitles.json | `words_per_screen` | 4 | 3–5 слов, читается с телефона |
| subtitles.json | `highlight` / `highlight_color` | on / FFFF00 | Жёлтая подсветка звучащего слова |
| vizard (SKILL.md) | `subtitleSwitch` | 0 | Свои субтитры в нашем стиле, с подсветкой |

Постоянные правила от Анны: смотрит с телефона (размеры с запасом); отчёт
цифрами; результат не выдумывать; куки и Vizard-ключ не трогать; таймеров и
отложенных самопроверок не ставить.

## Что не работает / отложено

1. **Звук — гулкость/звон/гул (НЕ закрыто).** Анна на телефоне услышала: голос
   гулкий («из бочки», комната ~200–500 Гц), звенят шипящие С/Ш/Щ/Ж, фоновый гул.
   Собран компаратор `audio-fix.yml` + `audio_clean.py --audiofix`: 5 вариантов на
   послушать (current / nodenoise / deesser / deesser_deboom / denoise_low) + замер
   полосы 4–8 кГц. По цифрам шумодав верх НЕ задирает (звон — вероятно «музыкальный
   шум» afftdn). **Анна финальный вариант НЕ выбрала** — деэссер (`deesser`) и вырез
   гула (`deboom`) в `audio.json` пока OFF. Ждём её выбор.
2. **Отложенные хвосты по звуку:** пик -0.7 вместо -1, режим loudnorm Dynamic —
   «на потом» (Анна).
3. **Vizard 03a-cut не прогонялся сквозняком.** Нужно: (а) секрет
   `VIZARDAI_API_KEY`; (б) Vizard должен резать ОБРАБОТАННЫЙ локальный файл
   `clip_color.mp4` (загрузка файла), а не ссылку YouTube — вызов Vizard под это
   ещё не переделан.
4. **transcript.json → куски.** После нарезки на несколько вертикальных кусков
   времена `transcript.json` (целого ролика) надо сопоставлять с таймлайном каждого
   куска, иначе субтитры не сойдутся. Не реализовано.
5. **Сквозного прогона (все этапы подряд) не было** — каждый этап проверялся
   отдельной кнопкой `*-test.yml`.
6. **Надёжное скачивание целого ролика:** хак `--download-sections *0-999999` в тесте
   нестабилен (обрывается). Для теста берём короткий отрезок. Отдельная задача.
7. **Whisper пляшет** от запуска к запуску (распознаёт чуть иначе) — влияет на
   качество расшифровки/субтитров.
